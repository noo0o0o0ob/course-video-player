# 课程工作台 · 原生桌面界面重设计

日期：2026-10-13
状态：已确认（方案 A）

## 1. 背景与目标

现有界面是网页式卡片布局（Element Plus、小字号 11–13px、顶栏品牌横条），不像桌面软件。本次全部推翻重做为**标准 Windows exe 界面**：简约、年轻化、一看就懂。

硬性要求：

1. **功能一个都不丢失**（以现有 15 条行为测试为验收清单）
2. **删除顶部横条**（品牌标题 + 计数统计条）
3. **尽量不翻页、全部平铺**：无标签页、无抽屉、无分页，所有功能同屏可见
4. **字大**、**列表不拥挤**、信息不挤在一起
5. **拖动窗口调整大小时信息不换行**（截断省略，不折行）
6. **浅色为主，可切换深色**
7. 不做无障碍优化；不要求组件库（去掉 Element Plus）

## 2. 整体布局（方案 A：原生三栏工作区）

```
┌──────────────── Windows 原生标题栏（系统按钮保留） ────────────────┐
│  ┌──────────┐  ┌────────────────────────┐  ┌──────────────────┐   │
│  │ 账号      │  │ 课程 + 章节             │  │ 当前任务 + 播放    │   │
│  │ 账号列表  │  │ 搜索 / 待学 / 已完成     │  │ 任务上下文        │   │
│  │ 添加账号  │  │ 章节列表                │  │ 4 个控制按钮      │   │
│  │ 表单      │  │                        │  │ 2 条进度          │   │
│  └──────────┘  └────────────────────────┘  └──────────────────┘   │
│  ┌───────────────────── 运行日志（全宽）──────────────────────┐   │
│  └────────────────────────────────────────────────────────────┘   │
│  状态条：计数 · 播放状态 · 深浅色切换                                │
└───────────────────────────────────────────────────────────────────┘
```

- 窗口默认 **1360×860**，最小 **1120×720**（原 1280×860 / 900×640）
- 三栏最小宽：左 300px、中 420px、右 320px；栏间距 14px
- 品牌名「课程工作台」只出现在原生窗口标题栏（`BrowserWindow` title）
- 原副标题、页脚引导语取消，引导内容改写进各空状态提示

- 回退栈：`"MiSans", "Segoe UI", "Microsoft YaHei", sans-serif`
- 引用用相对路径（Vite `base: './'` 已就绪），保证 Electron `file://` 下可用

## 5. 拖窗口不换行（硬约束）

- 所有名称/文案/按钮文字：`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`
- 截断元素带 `title` 属性，悬停显示全文
- 表格式行固定列宽：章节序号 40px、状态 72px、时长 72px，名称列 `minmax(0, 1fr)` 截断
- 三栏 `minmax(300px, 1fr) minmax(420px, 1.8fr) minmax(320px, 1.2fr)`；缩到最小窗口时宁可截断也不折行
- 按钮行 `flex-wrap: nowrap`；四个播放按钮 2×2 网格、文字单行
- 表单标签与输入框单行排列，输入框内文字不折行
